# Rock Paper Scissors

## Demo
https://joshua-2333.github.io/rock-paper-scissors/

A classic Rock Paper Scissors game built with JavaScript, allowing users to play against the computer with real-time results and score tracking. This project focuses on core programming logic, user interaction, and dynamic UI updates.

---

## Features

- Play against a computer opponent  
- Randomized computer choices  
- Game logic for win/lose/draw outcomes  
- Score tracking system  
- Multiple rounds gameplay  
- Instant feedback after each round  
- Responsive design *(if UI implemented)*  

---

## Built With

- HTML5  
- CSS3  
- JavaScript (ES6+)  

---

## Overview

Rock Paper Scissors is a simple hand game where each choice beats one option and loses to another (rock beats scissors, scissors beats paper, paper beats rock). :contentReference[oaicite:0]{index=0}  

This project recreates that logic in the browser and demonstrates:

- Random value generation for computer moves  
- Conditional logic for determining winners  
- Event handling for user input  
- Dynamic updates to the UI and score  

---

## How to Play

1. Select **Rock**, **Paper**, or **Scissors**  
2. The computer randomly selects its move  
3. The winner is determined instantly  
4. Scores update after each round  
5. Keep playing to beat your high score!
